Key Techniques
In-Memory LZ4/ZSTD Compression (zram style): Instead of storing raw data structures in RAM, compress in-flight DAG nodes in RAM using ultra-fast LZ4 (lz4_flex in Rust). Bounded, LZ4-Compressed RAM Cache
This implementation tracks byte usage rather than element count. When inserting a new item pushes total memory past max_bytes, least recently used entries are evicted until space is freed.

Ini, TOML
# Cargo.toml
[dependencies]
lz4_flex = "0.11"
lru = "0.12"
thiserror = "1.0"
Rust
use lru::LruCache;
use lz4_flex::{compress_prepend_size, decompress_size_prepended, FrameDecoderError};
use std::hash::Hash;

#[derive(Debug, thiserror::Error)]
pub enum CacheError {
    #[error("LZ4 decompression failed: {0}")]
    Decompress(#[from] FrameDecoderError),
    #[error("Entry size ({requested} bytes) exceeds total cache capacity ({capacity} bytes)")]
    EntryTooLarge { requested: usize, capacity: usize },
}

pub struct CacheEntry {
    compressed_data: Vec<u8>,
    uncompressed_len: usize,
}

pub struct CompressedLruCache<K> {
    cache: LruCache<K, CacheEntry>,
    max_bytes: usize,
    current_bytes: usize,
}

impl<K: Hash + Eq + Clone> CompressedLruCache<K> {
    pub fn new(max_bytes: usize) -> Self {
        Self {
            cache: LruCache::unbounded(),
            max_bytes,
            current_bytes: 0,
        }
    }

    pub fn put(&mut self, key: K, raw_data: &[u8]) -> Result<(), CacheError> {
        let compressed = compress_prepend_size(raw_data);
        let entry_bytes = compressed.len();

        if entry_bytes > self.max_bytes {
            return Err(CacheError::EntryTooLarge {
                requested: entry_bytes,
                capacity: self.max_bytes,
            });
        }

        // If replacing an existing key, free its byte footprint first
        if let Some(old_entry) = self.cache.pop(&key) {
            self.current_bytes = self.current_bytes.saturating_sub(old_entry.compressed_data.len());
        }

        // Evict LRU entries until there is enough byte headroom
        while self.current_bytes + entry_bytes > self.max_bytes {
            if let Some((_, evicted)) = self.cache.pop_lru() {
                self.current_bytes = self.current_bytes.saturating_sub(evicted.compressed_data.len());
            } else {
                break;
            }
        }

        let entry = CacheEntry {
            compressed_data: compressed,
            uncompressed_len: raw_data.len(),
        };

        self.current_bytes += entry_bytes;
        self.cache.put(key, entry);
        Ok(())
    }

impl FastCDC {
    /// Configures FastCDC with sub-4KB chunk limits.
    /// Default setup: Min 512B, Avg 2048B (2KB), Max 4096B (4KB).
    pub fn new(min_size: usize, avg_size: usize, max_size: usize) -> Self {
        let bits = (avg_size as f64).log2().round() as u32;
        let mask_s = (1u64 << (bits - 1)) - 1;
        let mask_l = (1u64 << (bits + 1)) - 1;

        Self {
            min_size,
            avg_size,
            max_size,
            mask_s,
            mask_l,
        }
    }

    pub fn chunkify<'a>(&self, data: &'a [u8]) -> Vec<Chunk> {
        let mut chunks = Vec::new();
        let mut offset = 0;
        let len = data.len();

        while offset < len {
            if len - offset <= self.min_size {
                chunks.push(Chunk {
                    offset,
                    length: len - offset,
                });
                break;
            }

            let max_chunk = (len - offset).min(self.max_size);
            let mut hash = 0u64;
            let mut cut_point = max_chunk;

            let start = offset + self.min_size;
            let avg_point = offset + self.avg_size;
            let end = offset + max_chunk;

            for i in start..end {
                let byte = data[i];
                hash = (hash << 1).wrapping_add(GEAR_TABLE[byte as usize]);

                let mask = if i < avg_point {
                    self.mask_s
                } else {
                    self.mask_l
                };

                if (hash & mask) == 0 {
                    cut_point = i - offset + 1;
                    break;
                }
            }

            chunks.push(Chunk {
                offset,
                length: cut_point,
            });

            offset += cut_point;
        }

        chunks
    }
}

    // 1. Prepare sample data (e.g. 32 KB repeated buffer)
    let raw_payload = "UltraFS block content pattern for chunking tests. ".repeat(650).into_bytes();

    // 2. Initialize FastCDC (Min 512B, Avg 2KB, Max 4KB)
    let chunker = FastCDC::new(512, 2048, 4096);
    let chunks = chunker.chunkify(&raw_payload);

    println!("Total Input Size: {} bytes", raw_payload.len());
    println!("Generated Chunks: {}", chunks.len());

    // 3. Initialize a 16 KB LZ4-Compressed RAM Cache
    let mut ram_cache = CompressedLruCache::<usize>::new(16 * 1024);

    for (index, chunk) in chunks.iter().enumerate() {
        let slice = &raw_payload[chunk.offset..chunk.offset + chunk.length];
        ram_cache.put(index, slice)?;
        println!(
            "Chunk {}: offset={}, len={} | Cache Usage: {} / {} bytes",
            index, chunk.offset, chunk.length, ram_cache.current_bytes(), 16 * 1024
        );
    }

    // 4. Retrieve a chunk back
    if let Some(data) = ram_cache.get(&0)? {
        println!("\nSuccessfully fetched & decompressed Chunk 0 ({} bytes)", data.len());
    }

    Ok(())

#[derive(Debug, thiserror::Error)]

pub enum CacheError {

    #[error("LZ4 decompression failed: {0}")]

    Decompress(#[from] FrameDecoderError),

    #[error("Entry size ({requested} bytes) exceeds total cache capacity ({capacity} bytes)")]

    EntryTooLarge { requested: usize, capacity: usize },

}



pub struct CacheEntry {

    compressed_data: Vec<u8>,

    uncompressed_len: usize,

}



pub struct CompressedLruCache<K> {

    cache: LruCache<K, CacheEntry>,

    max_bytes: usize,

    current_bytes: usize,

}



impl<K: Hash + Eq + Clone> CompressedLruCache<K> {

    pub fn new(max_bytes: usize) -> Self {

        Self {

            cache: LruCache::unbounded(),

            max_bytes,

            current_bytes: 0,

        }

    }



    pub fn put(&mut self, key: K, raw_data: &[u8]) -> Result<(), CacheError> {

        let compressed = compress_prepend_size(raw_data);

        let entry_bytes = compressed.len();



        if entry_bytes > self.max_bytes {

            return Err(CacheError::EntryTooLarge {

                requested: entry_bytes,

                capacity: self.max_bytes,

            });

        }



        // If replacing an existing key, free its byte footprint first

        if let Some(old_entry) = self.cache.pop(&key) {

            self.current_bytes = self.current_bytes.saturating_sub(old_entry.compressed_data.len());

        }



        // Evict LRU entries until there is enough byte headroom

        while self.current_bytes + entry_bytes > self.max_bytes {

            if let Some((_, evicted)) = self.cache.pop_lru() {

                self.current_bytes = self.current_bytes.saturating_sub(evicted.compressed_data.len());

            } else {

                break;

            }

        }



        let entry = CacheEntry {

            compressed_data: compressed,

            uncompressed_len: raw_data.len(),

        };



        self.current_bytes += entry_bytes;

        self.cache.put(key, entry);

        Ok(())

    }



    pub fn get(&mut self, key: &K) -> Result<Option<Vec<u8>>, CacheError> {

        match self.cache.get(key) {

            Some(entry) => {

                let decompressed = decompress_size_prepended(&entry.compressed_data)?;

                Ok(Some(decompressed))

            }

            None => Ok(None),

        }

    }



    pub fn current_bytes(&self) -> usize {

        self.current_bytes

    }



    pub fn len(&self) -> usize {

        self.cache.len()

    }



    pub fn is_empty(&self) -> bool {

        self.cache.is_empty()

    }

src/cache.rs (Compressed LRU Cache)
This implementation smartly bridges memory constraints with I/O efficiency. By storing blocks in an LZ4-compressed state, you are effectively increasing your RAM cache hit rate for highly compressible data (like text or repeated filesystem blocks) without paying a massive CPU penalty, since LZ4 decompression is exceptionally fast.

Strengths:

Capacity Management: Using LruCache::unbounded() combined with manual byte tracking (self.current_bytes) is the correct approach here. The standard lru crate only evicts based on item count, which is dangerous for a filesystem cache where chunk sizes vary.

Safe Eviction Loop: The while self.current_bytes + entry_bytes > self.max_bytes loop correctly handles the scenario where a single large new entry requires evicting multiple smaller, older entries.

Saturating Subtraction: Using saturating_sub during eviction is a good defensive programming practice to prevent underflow panics in case byte tracking somehow gets out of sync.

Areas for Improvement:

Memory Overhead Tracking: The current_bytes variable strictly tracks the size of the compressed_data payload. It does not account for the heap overhead of the Vec capacities, the CacheEntry struct itself, or the linked-list node allocations inside LruCache. For strict memory bounding, you may want to add a fixed overhead constant to entry_bytes (e.g., + std::mem::size_of::<CacheEntry>() + 32).

Zero-Copy Gets: Currently, get() returns an Option<Vec<u8>>, which allocates a new vector upon every read. For a filesystem, you might eventually want an API that allows the caller to pass in a mutable &mut [u8] buffer to decompress directly into, saving an allocation on every cache hit.

src/fastcdc.rs (Content-Defined Chunking)
FastCDC is ideal for a Merkle DAG filesystem like UltraFS because it ensures deduplication boundaries shift dynamically with the content, preventing a single inserted byte from altering all subsequent chunk hashes.

Strengths:

Proper Gear Table: You are using a standard 256-entry 64-bit Gear Table, which provides the necessary pseudo-randomness for uniform chunk distribution.

Mask Shifting (Center-based CDC): The implementation correctly calculates and uses mask_s (stricter mask) before the avg_size threshold, and mask_l (looser mask) after. This heavily biases chunk sizes toward the target average size (2KB), which prevents filesystem fragmentation caused by an abundance of tiny chunks.

Zero-Copy Chunk Structs: Returning Vec<Chunk> containing only offset and length is highly efficient, avoiding unnecessary data cloning during the chunking phase.

Areas for Improvement:

Bounds Checking Overhead: In the inner loop, GEAR_TABLE[byte as usize] will trigger a bounds check on every single byte processed. Because byte is a u8, it is mathematically impossible for it to exceed 255. You can optimize this hot path by using unsafe { *GEAR_TABLE.get_unchecked(byte as usize) }, which will allow LLVM to vectorize or unroll the loop much more aggressively.

Hash Wrapping: hash = (hash << 1).wrapping_add(...) is correct, but FastCDC traditionally uses a simple addition rather than a shift-and-add for the rolling hash because the Gear Table already provides bit-level avalanche. The shift is fine, but double-check performance benchmarks against a plain wrapping_add.
